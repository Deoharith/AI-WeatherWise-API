
# Brainstorming & Ideation

## Project Title
AI WeatherWise API

## Problem Statement
People need a simple way to obtain current weather information for a city and understand the weather conditions through useful recommendations.

## Idea
AI WeatherWise API is a REST API that retrieves real-time weather information for a selected city and generates smart weather advice based on the current weather conditions.

## Main Features
- City-based weather search
- Real-time weather information
- Temperature, humidity and wind speed
- Weather condition detection
- Smart weather advice
- Error handling
